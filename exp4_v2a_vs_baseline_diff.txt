KEY INSIGHT
================================================================================

This configuration tests R3's large-batch hypothesis FAIRLY by:
1. Matching data exposure (3.2M samples)
2. Scaling LR linearly with batch size (Goyal et al. 2017)
3. Maintaining same relative schedule (warmup at 5%, unfreeze at 5%, etc.)
4. Using SHARP multi-positive method (not vanilla contrastive)

If v2a performs similarly to baseline, large batch provides NO advantage.
If v2a outperforms baseline, large batch DOES help (controlling for data).
