## Analysis

### Performance Gap

**SHARP significantly underperforms BenchX baselines** on the F1 metric, despite:
- ✅ Using identical training protocol (SGD, lr=1e-2, bs=64)
- ✅ Same backbone architecture (ViT-B)
- ✅ Same data splits (1%, 10%, 100%)
- ✅ Reasonable AUROC scores (0.69-0.79)
- ✅ Reasonable accuracy (75-80%)

### Class Imbalance Issue

RSNA validation set is **highly imbalanced**:
- Negative (no pneumonia): 77.5% (3,101 samples)
- Positive (pneumonia): 22.5% (902 samples)

**F1 is sensitive to class imbalance** - a model biased toward the negative class can have high accuracy but low F1.

### Possible Causes

1. **Pretraining domain mismatch**
   - SHARP pretrained on MIMIC-CXR reports
   - May not transfer well to RSNA pneumonia detection

2. **Checkpoint quality**
   - Exp #3 checkpoint (p3_best.pt) might not be optimal
   - Stage 2 F1 was ~36%, indicating potential issues

3. **Classification head initialization**
   - Linear probe on frozen features?
   - Full finetuning with wrong hyperparameters?

4. **Decision threshold**
   - Default 0.5 threshold may be suboptimal for imbalanced data
   - BenchX baselines might tune threshold or use class weights

5. **Loss function**
   - Using CrossEntropyLoss without class weights
   - BenchX might use weighted loss for imbalanced data

## Training Details

### Dataset Splits Generated by BenchX

- **train_1.txt**: 1% of train (186 samples)
- **train_10.txt**: 10% of train (~1,800 samples)
- **train.txt**: 100% of train (~18,000 samples)
- **val.txt**: Validation set (4,003 samples)
- **test.txt**: Test set (unused in these experiments)

### Training Protocol (Matches MGCA Exactly)

```yaml
optimizer: SGD
lr: 1e-2 (with 0.1x multiplier for backbone)
momentum: 0.9
batch_size: 64
warmup: 50 steps
lr_schedule: WarmupCosineScheduler (3000 steps)
early_stop: 10 epochs patience
early_stop_metric: multiclass_auroc
```
